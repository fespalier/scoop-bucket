# fespalier Scoop bucket

The Scoop manifest for [`fsp`](https://github.com/fespalier/fespalier), the generator behind
fespalier's file-tree routing for Flutter.

```powershell
scoop bucket add fespalier https://github.com/fespalier/scoop-bucket
scoop install fsp
```

`bucket/fsp.json` is written by fespalier's release workflow on every release, from the archives it
has verified against the checksums pinned in the release. Don't edit it by hand: a change here is
overwritten by the next release. Report problems in
[fespalier/fespalier](https://github.com/fespalier/fespalier/issues).
